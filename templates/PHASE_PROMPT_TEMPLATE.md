## [BLOCKING] Pre-flight gate

Run these commands BEFORE writing any code. If any step fails, STOP and surface the failure to the user. Do NOT attempt fixes autonomously.

```bash
cd $(git rev-parse --show-toplevel)
git status                    # working tree must be clean
make check-index              # CODEBASE_INDEX.md must be fresh
git log -1 --format=%H        # record starting commit for postflight diff
```

**Stop conditions (each is a hard fail-stop):**
1. `git status` shows uncommitted changes → ask user how to proceed
2. `make check-index` exits non-zero → a previous phase bypassed the hook; surface the diff and stop
3. The user's task description references files NOT listed in `## Scope` → confirm scope before proceeding

## [BLOCKING] Post-flight verification

After all implementation commits but BEFORE handing back to the user:

```bash
make index                                    # regenerate (will be no-op if hook fired)
git diff $(git log -1 --format=%H BEFORE_PHASE_COMMIT) -- CODEBASE_INDEX.md
```

**Verify:**
1. The index diff contains only changes to symbols listed in `## Scope`. Any symbol added/removed outside scope is a bug — STOP and surface it.
2. All tests pass (backend + frontend + tsc).
3. `git log` shows exactly the commits described in `## Implementation steps`, in order.
4. No `--no-verify` was used (pre-commit hook ran on every commit).

If any of those four checks fail, do not declare the phase complete. Surface the failure.

## Forbidden patterns

The following patterns are explicit fail conditions. Stop and ask if you find yourself reaching for any of these:

- "Let me check what `<ModelName>` looks like by reading `models.py`" → use the ground-truth block above instead. If it's not there, the prompt is incomplete — ask the user to add it.
- "I'll add a quick fix to `<file outside Scope>`" → out of scope is out of scope.
- "The docs say X but the code says Y, I'll silently follow the code" → flag the conflict explicitly.
- `git commit --no-verify` → never. The hook is the contract.
- "I'll regenerate `CODEBASE_INDEX.md` by hand to match my changes" → only the script generates the index.
